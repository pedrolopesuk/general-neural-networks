# MetaBrain — The Recursive Emotional Brain Simulation

A high-performance **C++20 / AVX2 Recursive Neural Graph Engine** implementing the **Composite Design Pattern** (`Neuron` holons dynamically instantiating nested child micro-circuits), a **Global Neuromodulatory Endocrine System** (*Fear/Anxiety, Dopamine/Reward, Fatigue/Sadness, Curiosity*), **Three-Factor Oja-Stabilized Hebbian + Backpropagation Learning**, **JSON & GraphML Graph Serialization**, **Unreal Engine 5.8 Niagara VFX C++ Integration**, and an **Interactive 3D Glassmorphic Brain Studio**.

---

## Quick Start

### 1. Build & Run C++20 Engine + Benchmarks (MSVC 2026 + Ninja)
From a Visual Studio x64 Developer Prompt (or PowerShell):
```powershell
cmd /c "`"C:\Program Files (x86)\Microsoft Visual Studio\18\BuildTools\Common7\Tools\VsDevCmd.bat`" -arch=x64 && cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build build"
.\build\metabrain_tests.exe
.\build\metabrain.exe
```

### 2. Launch Interactive 3D Force-Directed Glassmorphic Brain Studio
- **Zero-Server Mode**: Open `visualizer/index.html` directly in any modern browser (uses `visualizer/brain_preload.js` generated by `metabrain.exe`).
- **Live C++20 Telemetry Mode**:
  ```powershell
  .\build\metabrain.exe --serve 8085
  ```
  Then open **http://127.0.0.1:8085/** in your browser.

### 3. Unreal Engine 5.8 Niagara VFX Integration
Copy `include/metabrain/`, `src/` (excluding `main.cpp`), and `ue5_integration/*` into your UE 5.8 project's `Source/MetaBrain/` module directory, add `"MetaBrain"` to your `.uproject` / `Target.cs`, and bind `UNiagaraDataInterfaceMetaBrain` to your Soma & Synapse Ribbon emitters.
